## 📦 Core Function (Human-crafted)

```js
function genFizzBuzz(rules, num) {
    let result = "";
    for (let [factor, word] of rules) {
        if (num % factor === 0) result += word;
    }
    return result || num.toString();
}
```

Clean. Efficient. Battle-tested. Ready for production.
